# Persona Toolbar

The Persona toolbar hosts the current Personas available in Affinity Photo 2.

### Settings (or Preferences)

The following options are available from the Toolbar:

- ![Photo Persona](../../assets/shared/ui/photo_persona_on.png) **Photo Persona**—provides the core set of photo editing tools.
- ![Liquify Persona](../../assets/shared/ui/liquify_persona_on.png) **Liquify Persona**—switches to warping tools for retouch and special distortion effects.
- ![Develop Persona](../../assets/shared/ui/develop_persona_on.png) **Develop Persona**—switches to a tonal and lens correction environment with support for raw image development.
- ![Tone Map Persona](../../assets/shared/ui/tonemap_persona_on.png) **Tone Mapping Persona**—moves to an environment for tone mapping HDR and non-HDR imagery through global and local contrast.
- ![Export Persona](../../assets/shared/ui/export_persona_on.png) **Export Persona**—switches to a slice-based image export environment.

> **Note:**
>
> **macOS:**
>
> The active Persona can also be switched by accessing the top **Affinity Photo 2** menu.
>
> **Windows:**
>
> The active Persona can also be switched by accessing the top **File** menu.
