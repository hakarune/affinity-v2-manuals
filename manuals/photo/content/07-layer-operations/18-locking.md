# Locking

Locking is useful when you need to prevent a layer from being moved or transformed unintentionally.

**To lock a layer:**

1. On the **Layers** panel, select the layer to be locked.
2. Do one of the following:
  - Select **Lock/Unlock**.
  - From the **Layer** menu, select **Lock**.

Select **Lock/Unlock** again, or use the **Layer** menu's **Unlock** item, to allow the layer to be editable.

> **Tip:** To quickly lock an individual layer or object, position the cursor to the left of its visibility button on the Layers panel and click the lock icon that appears.

> **Note:** Layers which are locked show in the Layers panel with a lock symbol, ![Locked layer](../../assets/shared/ui/locked_layer.png), next to them. Selected locked layers appear with crosses around the bounding box.

> **Note:** Opened images, or images developed from Develop Persona, appear as a locked background layer by default.

**To unlock all layers:**

- From the **Layer** menu, select **Unlock All**.

> **Note:** If any locked layer(s) is selected before Unlock All is applied, only that layer will be unlocked, instead of all layers.
