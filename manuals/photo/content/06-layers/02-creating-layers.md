# Creating layers

Empty layers can be created in the Layers panel or from the Layer menu. Layers are created above the currently selected layer. Once created, layers can be renamed for easy identification.

**To create a new layer:**

Do one of the following:

- From the **Layers** panel, click **Add Layer**.
- From the **Layer** menu, select **New Layer**.
- With no layers selected, paint on your page with the **Paint Brush Tool**. By default, the [Assistant](../37-settings-preferences/01-settings-preferences.md) will create a new layer to accommodate your paint strokes.

**To rename a layer:**

Do one of the following:

- Double-click the layer's label and type a new name.
- On the **Layer** menu, select **Rename Layer**.

**To rename layers sequentially:**

1. Select a layer in the stack and start renaming as described above.
2. Use the `Tab` and `Shift`+`Tab` keyboard shortcuts to switch between layers.
3. Enter a new layer name when ready.

The `Tab` will take you to the layer lower down the stack, whereas `Shift`+`Tab` switches to the layer higher up.

You can enable **Ask for name when creating Layers and Groups** setting to be prompted to name them upon creation. This is found in the **Settings (or Preferences)>User Interface** section.

**To duplicate a layer within the same document:**

Do one of the following:

- **macOS:** With the **Move Tool** enabled, `Cmd`-drag the selected layer content on the page.
- **Windows:** With the **Move Tool** enabled, `Ctrl`-drag the selected layer content on the page.
- `Alt`-drag the selected layer up or down in the layer stack.
- With a layer pre-selected, from the **Layer** menu, select **Duplicate**.
- With a layer pre-selected, from the **Edit** menu, select **Copy**, then **Paste**.

The latter can also be performed between documents.

> **Note:** You can also copy and paste selections and layer groups using the **Edit>Copy** and **Edit>Paste** method. If you copy a layer group, all layers within the group will be duplicated.

> **Tip:** You can duplicate an object to another 'floating' document by dragging and dropping its layer onto the target's document view.

>
> - **Miscellaneous>Reset Object Styles**
