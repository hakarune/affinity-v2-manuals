# Marquee pixel selections

The marquee selection tools allow you to create selections based on standard geometric shapes, such as ellipses and rectangles.

## Selection tools

There are several marquee tools you can use to create pixel selections:

- ![Rectangular Marquee Tool](../../../assets/shared/ui/rectangular_marquee_tool.png) **Rectangular Marquee Tool**—creates a rectangular or square selection.
- ![Elliptical Marquee Tool](../../../assets/shared/ui/elliptical_marquee_tool.png) **Elliptical Marquee Tool**—creates an elliptical or circular selection.
- ![Column Marquee Tool](../../../assets/shared/ui/column_marquee_tool.png) **Column Marquee Tool**—creates a rectangular selection of the set pixel width which spans the entire image's height.
- ![Row Marquee Tool](../../../assets/shared/ui/row_marquee_tool.png) **Row Marquee Tool**—creates a rectangular selection of the set pixel height which spans the entire image's width.

> **Note:** For pixel-accurate selection, **Force Pixel Alignment** on the top Toolbar will snap pixel selection areas to full pixels when created, moved or modified. If this option is off, selections can occupy partial pixels.
>
> Furthermore, if [snapping](../../30-design-aids/11-snapping.md) is active, selection areas can snap to page edges and [guides](../../30-design-aids/05-ruler-and-column-guides.md) when being created (using the Marquee Selection Tools) or moved.

**To create a pixel selection:**

- With a marquee selection tool selected, drag on your page.

> **Note — Modifier keys:** The following modifier keys can be used to aid in the creation of selections:
>
> - The `Shift`  constrains a Marquee Tool's proportions.
> - The `Alt`  automatically removes areas from the current selection.
> - **macOS:** The `Ctrl`  automatically adds areas to the current selection.
> - **Windows:** Drag with left and right button down (Marquee and Freehand Selection Tools) to automatically add areas to the current selection.
> - The `Spacebar` repositions a rectangular or elliptical marquee selection as it is being drawn.

**To set the width of a column/row selection:**

- With the **Column Marquee Tool** or **Row Marquee Tool** selected, on the context toolbar, adjust the **Width** setting.
