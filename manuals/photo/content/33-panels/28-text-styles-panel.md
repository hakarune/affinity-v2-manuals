# Text Styles panel

The **Text Styles** panel gives you access to all the text styles in your document, allowing you to apply them, modify them, delete them or create new ones.

> **Note:** This panel is hidden by default. It can be switched on via **Window>Text**.

## About the Text Styles panel

The **Text Styles** panel shows you which styles are applied to the current selection and gives you the option to apply paragraph and character styles at the caret position or to selected text.

The panel also gives you options for creating new paragraph and character styles, redefining existing styles, or deleting them.

Furthermore, there are options for setting specific text styles as defaults and for importing text styles from other projects.

For more information on using text styles, see [Using text styles](../26-text/13-text-styles/01-using-text-styles.md).

### Display preferences

![Text Styles panel](../../assets/images/panel_textstylesoptions.png)
*The Text Styles panel showing Display preferences.*

There are several options, available from panel preferences, which allow you to change how styles are displayed in the panel:

- **Show Hierarchical**—styles appear nested below styles which they are **Based on**.
- **Show Samples**—when selected (default), a style's appearance mirrors what will be seen on the page. If this option is off, styles will all show as plain text.
- **Sort By Type**—when selected (default), paragraph styles are listed first, followed by character styles. If this option is off, styles are listed purely in alphabetical order.

### Options

The following options are available in the panel:

- **Current Formatting**—displays the formatting applied to the selected text or at the current caret's position. Click the arrow to the left to display overflowing information, if necessary.
- ![Reapply text styles](../../assets/shared/ui/ReapplyTextStyles.png) **Reapply Text Styles**—removes local formatting from the selected text, ensuring it honors the Current Formatting perfectly.
- ![Paragraph text style](../../assets/shared/ui/ParagraphStyle.png) ![Character text style](../../assets/shared/ui/CharacterStyle.png) Type—specifies whether the text style is a [paragraph, character or group type](../26-text/13-text-styles/04-text-style-types.md).
- Text style—displays the name of text styles currently available in the document.
- Keyboard shortcut—displays the key combination necessary to apply the text style. A shortcut must first be applied to a text style.
- ![Panel Preferences](../../assets/shared/ui/moremenuicon.png) Options menu—provides access to a pop-up menu with creation and editing options.
- ![Create Paragraph Style](../../assets/shared/ui/CreateParagraphStyle.png) **Create Paragraph Style**—launches the **Edit Text Style** dialog ready for [creating a new paragraph style](../26-text/13-text-styles/02-creating-and-managing-text-styles.md).
- ![Create Character Style](../../assets/shared/ui/CreateCharacterStyle.png) **Create Character Style**—launches the **Edit Text Style** dialog ready for [creating a new character style](../26-text/13-text-styles/02-creating-and-managing-text-styles.md).
- ![Create Style](../../assets/shared/ui/CreateGroupStyle.png) **Create Group Style**—launches the **Edit Text Style** dialog ready for [creating a new group style](../26-text/13-text-styles/02-creating-and-managing-text-styles.md).
- ![Update Paragraph Style](../../assets/shared/ui/UpdateParagraphStyle.png) **Update Paragraph Style**—redefines the current paragraph style to conform with the local formatting of the selected text.
- ![Update Character Style](../../assets/shared/ui/UpdateCharacterStyle.png) **Update Character Style**—redefines the current character style to conform with the local formatting of the selected text.
- ![Delete Style](../../assets/shared/ui/trash_can.png) **Delete Style**—removes the selected paragraph or character style from the document and any instances of their application.
