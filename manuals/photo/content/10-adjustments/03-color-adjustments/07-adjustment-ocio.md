# OpenColorIO adjustment

The **OpenColorIO** adjustment is designed to help with OpenColorIO color-managed workflows by allowing color transforms between source and destination color spaces. See [Using OpenColorIO](../../16-hdr/05-using-opencolorio.md) for more information.

![Before](../../../assets/shared/adjustment_ocio_before.jpg)
![After](../../../assets/shared/adjustment_ocio_after.jpg)
*Before (ACEScg) and after (Linear sRGB) adjustment applied.*

### Settings

The following settings can be adjusted:

- **Source Color Space**—sets the input color space to use for transforming.
- **Destination Color Space**—sets the output color space.

> **Tip:** This adjustment requires a valid OpenColorIO configuration in order to be usable. See [Using OpenColorIO](../../16-hdr/05-using-opencolorio.md) for instructions on setting up a configuration.
