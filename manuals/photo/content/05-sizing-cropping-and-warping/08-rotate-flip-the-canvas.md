# Rotate/flip the canvas

The canvas and its contents can be flipped and rotated permanently using the commands from the Document menu.

> **Note:** If you wish to temporarily rotate the canvas, viewing your content from a different angle without altering it, this can be done from the **View** menu or by using a Trackpad. See [Rotate document view](../30-design-aids/10-rotate-canvas.md) for more information.

**To flip the canvas horizontally:**

- From the **Document** menu, select **Flip Horizontal**.

**To flip the canvas vertically:**

- From the **Document** menu, select **Flip Vertical**.

**To rotate the canvas 90 degrees anti-clockwise:**

- From the **Document** menu, select **Rotate Anti-clockwise**.

**To rotate the canvas 90 degrees clockwise:**

- From the **Document** menu, select **Rotate Clockwise**.
