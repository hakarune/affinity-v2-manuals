# Slice Tool

The **Slice Tool** allows you to create and edit export areas so you can select portions of your page to be exported as individual raster images.

> **Note:** Available in Export Persona only.

### Settings

The following settings can be adjusted from the context toolbar:

- **Revert to auto sized**—resets the dimensions of a resized slice created from a layer back to its original size.
