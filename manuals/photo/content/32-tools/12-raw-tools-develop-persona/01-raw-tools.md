# Raw Tools

The Raw tools allow you to make and modify adjustments applied to an image in Develop Persona.

**The Raw tools available include:**

#### View Tool

Used to move the visible portion of your document in the document view.

#### Zoom Tool

Used to change the zoom level of your page or canvas in the document view.

#### Red Eye Removal Tool

Quickly [fixes the red eye effect](../../09-retouching/01-removing-red-eye.md) in your photos and preserves the detail of the eye.

#### Blemish Removal Tool

Enables you to [remove small imperfections](../07-retouch-tools/12-blemish-removal-tool.md) from images.

#### Overlay Paint Tool

Allows you to add areas to the [selected overlay adjustment](../../04-develop-persona-raw/07-overlays-panel.md).

#### Overlay Erase Tool

Allows you to remove areas of the [selected overlay adjustment](../../04-develop-persona-raw/07-overlays-panel.md).

#### Overlay Gradient Tool

Allows you to apply linear, elliptical, or radial graduated opacity to the [selected overlay adjustment](../../04-develop-persona-raw/07-overlays-panel.md).

#### Crop Tool

Removes areas of an image to improve composition.

#### White Balance Tool

Automatically sets the [White Balance](../../04-develop-persona-raw/03-basic-panel.md) of the image depending on the color of the pixel clicked under the tool's cursor or pixels selected by dragging (averaged color).
