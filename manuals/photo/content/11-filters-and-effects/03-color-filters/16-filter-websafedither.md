# Web Safe Dither

The Websafe Dither filter minimizes flat colors and loss of detail when reducing the color depth of your image. This helps make the image more acceptable for viewing on the web.

![Before](../../../assets/shared/filter_websafedither_before.jpg)
![After](../../../assets/shared/filter_websafedither_after.jpg)

## About the Web Safe Dither filter

This filter can be found in the **Filter** menu, in the **Colors** category.

This filter has no customizable settings.
