# Lighting/tonal filters

These filters can be used to adjust the contrast and lighting of images.

Available filters include:

| Filter name | Description | Regular filter    (destructive) | Live filter    (non‑destructive) |
| --- | --- | --- | --- |
| [Haze Removal](../11-haze-removal.md) | Removes slight to extreme cases of haze affecting an image. | ![check](../../../assets/shared/check.png) |  |
| [Lighting](../10-lighting.md) | Add one or more simulated light sources (ambient, point, direction and spot lighting). | ![check](../../../assets/shared/check.png) | ![check](../../../assets/shared/check.png) ![Lighting live filter type](../../../assets/shared/ui/lighting_live_filter.png) |
| [Shadows / Highlights](../09-shadows-highlights.md) | Manipulate tones to reduce contrast and improve detail in shadows and highlights. | ![check](../../../assets/shared/check.png) | ![check](../../../assets/shared/check.png) ![Shadows / highlights live filter type](../../../assets/shared/ui/shadows_highlight_live_filter.png) |
