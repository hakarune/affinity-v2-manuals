# Edge detection filters

Edge detection filters isolates and strengthens vertical edges, horizontal edges, or both, while darkening the rest of the image.

These filters are applied to your image from the **Filters** menu (destructive).

| Filter name | Description | Regular filter    (destructive) | Live filter    (non‑destructive) with layer symbol |
| --- | --- | --- | --- |
| [Detect Edges](05-edge-detection-filters/01-filter-detectedges.md) | Isolates all edges in your image. | ![check](../../assets/shared/check.png) |  |
| [Detect Horizontal Edges](05-edge-detection-filters/02-filter-detecthorizontaledges.md) | Isolates horizontal edges in your image. | ![check](../../assets/shared/check.png) |  |
| [Detect Vertical Edges](05-edge-detection-filters/03-filter-detectverticaledges.md) | Isolates vertical edges in your image. | ![check](../../assets/shared/check.png) |  |
