# OpenColorIO adjustment

The **OpenColorIO** adjustment is designed to help with OpenColorIO colour-managed workflows by allowing colour transforms between source and destination colour spaces. See [Using OpenColorIO](../06-colour/05-using-opencolorio.md) for more information.

![Before](../../assets/shared/adjustment_ocio_before.jpg)
![After](../../assets/shared/adjustment_ocio_after.jpg)
*Before and after OCIO adjustments applied to convert logo to the same colour space as the background render.*

### Settings

The following settings can be adjusted:

- **Source Colour Space**—sets the input colour space to use for transforming.
- **Destination Colour Space**—sets the output colour space.

> **Tip:** This adjustment requires a valid OpenColorIO configuration in order to be usable. See [Using OpenColorIO](../06-colour/05-using-opencolorio.md) for instructions on setting up a configuration.
