# OpenType font features

Affinity Designer provides support for OpenType font features. These extend the font's character set which lets you present text with a greater degree of typographical control.

![OpenType fonts example](../../assets/shared/opentype_fonts.png)
*Text example of an OpenType stylistic set using the font Gabriola.*

Font features supported include ligatures, alternates, swash variants, stylistic sets, and figure positions. You'll also get ligature control via the **Text** menu's **Ligatures** submenu.

**To apply OpenType font features:**

1. Assign a font to your text that supports OpenType font features.
2. From the **Text** menu, select **Show Typography**.
3. Adjust the settings in the dialog.

> **Note:** The available font features differ between fonts. This is dependent on how the font was designed by the font designer.

> **Note:** As OpenType fonts are cross-platform, you can make use of OpenType fonts from both Mac and Windows operating systems.
