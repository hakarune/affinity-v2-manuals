# Import and export file formats

Affinity Designer is capable of opening many raster and vector file formats directly. Designer also imports PDF and Adobe PSD files, and exports a range of raster file formats and the PSD file format.

| File type | Import | Export |
| --- | --- | --- |
| Affinity template |  | x |
| Adobe Illustrator (AI) | x<sup>1</sup> |  |
| Adobe Freehand (10 and MX) | x<sup>2</sup> |  |
| Adobe PhotoShop (PSD) | x | x<sup>8</sup> |
| BMP | x |  |
| DWG/DXF | x<sup>10</sup> |  |
| EPS | x | x |
| GIF | x | x |
| HEIF/HEIC/HIF | x<sup>3</sup> |  |
| JPEG | x | x |
| J2K,JP2 | x |  |
| JPEG-XR/JXR (WDP/HDP) | x<sup>9</sup> |  |
| JPEG-XL | x | x |
| PDF | x<sup>1,7</sup> | x<sup>8</sup> |
| PNG | x | x<sup>4</sup> |
| RAW | x<sup>5</sup> |  |
| SVG | x | x |
| TGA | x<sup>4</sup> | x |
| TIFF | x<sup>6</sup> | x<sup>4</sup> |
| WEBP | x | x |
| OpenEXR | x | x |
| Radiance HDR | x | x |

<sup>1</sup> Multi-page files can be imported, with each page being placed on its own artboard.

<sup>2</sup> Multi-page Freehand files open with each page concatenated onto a single page. Add file extension .fh10 or .fh11 in Finder to import. Text import is not supported.

<sup>3</sup> For iPhone images, the HEIC file may include an upsampled depth map, loaded as an editable second layer. For Canon EOS models (1 DX MkIII, R5 and R6), HIF files (HDR 10-bit PQ-encoded) can be opened.

<sup>4</sup> Supports transparency.

<sup>5</sup> For a comprehensive up-to-date list of RAW file support, please see the following links:

- [SerifLabs RAW](https://affin.co/rawlist) (Mac & Windows)
- [Apple Core Image RAW](https://affin.co/rawapple) (Mac only)

<sup>6</sup> 12 bit TIFF (RGB or Mono) included.

<sup>7</sup> JBIG2 PDF encoding is supported.

<sup>8</sup> Text will be rasterised on export.

<sup>9</sup> Includes JPEG-XR 101010 (e.g. XBOX screen captures).

<sup>10</sup> DWG (R12-R14, 2000-2018) and DXF (R9-R14, 2000-2018).
