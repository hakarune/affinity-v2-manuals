# About bit depth

Affinity Designer has several different [colour models](../06-colour/02-colour-models.md), some capable of working at 8 or 16 bit depth.

## Bit depth

Your document's bit depth refers to the amount of tonal or colour information that can be stored per pixel. The higher the bit depth, the more tonal information each pixel can store.

In Affinity Designer, you need to choose a colour format (mode) to work in when creating a [new document](02-create-new-documents.md). This sets the colour model and the bit depth (8 or 16 bits) for the document you are working on.

> **Note:** If you want to understand bit depth in greater detail, there is a wealth of information on the internet.
