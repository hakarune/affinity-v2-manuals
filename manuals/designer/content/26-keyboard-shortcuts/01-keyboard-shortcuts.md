# Keyboard shortcuts

**macOS:**

You can quickly access common tools and commands using your keyboard. Many of the shortcuts are the same as those that you use in other apps (such as `Cmd` + `C` to copy). You'll find many of the shortcuts listed next to menu items (and in the list below).

**Windows:**

You can quickly access common tools and commands using your keyboard. Many of the shortcuts are the same as those that you use in other apps (such as `Cmd`+`C` to copy). You'll find many of the shortcuts listed next to menu items (and in the list below).

For complete flexibility, you can [customise keyboard shortcuts](../21-workspace/customise/01-keyboard-shortcuts.md) to your own way of working.
