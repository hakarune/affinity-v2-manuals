# About layers

Layers let you organise the contents of your design into a logical tiered structure for better creative composition and object management.

![Layers example](../../assets/images/aboutlayers_designer.png)

## What are layers?

You can think of each layer as being like an individual drawer in a clothes chest of drawers. Within that drawer you place shirts or blouses that are stacked on top of each other. In layer management, these clothes items are our individual vector objects, sometimes overlapped, sometimes not. Using our analogy, if your chest of drawers was see-through and you looked directly down from above it, you would see the topmost drawer contents in the foreground, the bottom contents in the background, and all other contents ordered in between.

All layer management is carried out from the Layers panel.

Here are some important points regarding layers:

- The order of your layers is important. A layer at the *top* of the panel is shown in the *foreground* of your document view, with the lowest layer in the background.
- Any selected layer(s) are highlighted, so that you can always see what layer you are working on.
- You can create child layers, which are nested under a parent layer. Child layers are perfect for use as an extra level of object organisation in more complex documents.
- Any layer can be hidden, to exclude its layer objects from displaying in your design.

## Layer types

There are several types of layers that can be created; these are identified in the Layers panel with a unique icon, shown at the beginning of the layer entry.

| Panel icon | Description |
| --- | --- |
| ![Artboard layer icon](../../assets/shared/ui/artboard_layer_type.png) | Artboard—discrete design areas that can be sized to different page or mobile device sizes. |
| ![Vector layer icon](../../assets/shared/ui/layers_layer_type.png) | Vector—used for placing vector objects into. |
| ![Pixel layer icon](../../assets/shared/ui/pixel_layer_type.png) | [Pixel](02-create-layers.md)—used for pixel-based editing (Pixel Persona). |
| ![Shape layer icon](../../assets/shared/ui/shape_layer_type.png) | Shape—for geometric shapes created with shape tools. |
| ![Compound layer icon](../../assets/shared/ui/compound_layer_type.png) | Compound—for non-destructive compound shapes created by Boolean operations. |
| ![Curve layer icon](../../assets/shared/ui/curve_layer_type.png) | Curve—for open curves and closed shapes drawn with Pen Tool or Pencil Tool. |
| ![Artistic text layer icon](../../assets/shared/ui/artistic_text_layer_type.png) | Artistic Text—for scalable text. |
| ![Frame text layer icon](../../assets/shared/ui/text_box_layer_type.png) | Frame Text—for story text contained within a frame. |
| ![Path text layer icon](../../assets/shared/ui/path_text_layer_type.png) | Path Text—for text that follows an open curve or a shape's outline. |
| ![Shape text layer icon](../../assets/shared/ui/shape_text_layer_type.png) | Shape Text—for text contained within a shape. |
| ![Empty group layer icon](../../assets/shared/ui/empty_layer_type.png) | Empty group—an empty group container for containing multiple objects as a single object. |
| ![Mask layer icon](../../assets/shared/ui/mask_layer_type.png) | [Mask](11-layer-masking.md)—defines what content is hidden to reveal layers beneath. |
| ![Image layer icon](../../assets/shared/ui/image_layer_type.png) | [Image](09-image-layers.md)—self-contained placed images that retain the original image data including the colour profile. |
| ![Document layer icon](../../assets/shared/ui/embedded_layer_type.png) | Linked/Embedded document—placed non-native documents (such as PDF, PSD, SVG, EPS) and native Affinity documents (afphoto, afdesign and afpub) files. |
| ![Adjustment layer icon](../../assets/shared/ui/adjustment_layer_type.png) | [Adjustment](12-using-adjustment-layers.md)—used to correct or enhance a specific object, group, layer or the whole layer stack non-destructively. |
| ![Symbol layer icon](../../assets/shared/ui/symbol_layer_type.png) | Symbol—the symbolised object shares its properties with other symbolised objects so edits across objects are simultaneous. |
