 Artboard Tool

The **Artboard Tool** allows you to add, move and resize [artboards](../../04-artboards/01-about-artboards.md) within a document.

### Settings

The following settings can be adjusted from the context toolbar:

- **Size**—sets the preset size of the artboard to be added to the pasteboard.
- **Insert Artboard**—adds a new artboard to the pasteboard.
