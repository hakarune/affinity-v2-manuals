# ![Frame Text Tool](../../../assets/shared/ui/frame_text_tool.png)

 Frame Text Tool

The **Frame Text Tool** allows you to add a text frame which acts as a container for paragraph text.

Frame text is best suited to working with text which will be presented in paragraphs with a formalised structure and layout. If you want to present text in columns, frame text is the ideal solution.

> **Note:** The Artistic Text Tool and Frame Text Tool are grouped together on the **Tools** panel. Click the triangle in the bottom-right of the displayed icon to access the alternative tool.

### Settings

The following settings can be adjusted from the context toolbar:

- **Font Family**—sets the font of the text. Select from the pop-up menu.
- Font Style—click to display a pop-up menu with optional formats for the selected font.
- Font Size—type directly in the text box or drag the pop-up slider to set the value.
- **Bold**/**Italic**/**Underline**—select one or more of these to apply these properties to your text.
- **Font Colour**—click the colour swatch to display a pop-up panel to update fill colour.
- ![Character style](../../../assets/shared/ui/CharacterStyle.png)

   **Character Style**—applies a character style to the selected text. Select from the pop-up menu.
- ![Update Character style](../../../assets/shared/ui/UpdateCharacterStyle.png)

   **Update Character Style**—updates the character style of the selected text.
- ![Character](../../../assets/shared/ui/character_page.png)

   **Character**—provides access to the [Character](../../12-text/07-character-formatting.md) panel for advanced text settings.
- ![Paragraph style](../../../assets/shared/ui/ParagraphStyle.png)

   **Paragraph Style**—applies a paragraph style to the selected text or to the paragraph in which the caret currently resides. Select from the pop-up menu.
- ![Update Paragraph style](../../../assets/shared/ui/UpdateParagraphStyle.png)

   **Update Paragraph Style**—updates the paragraph style of the selected text.
- ![Paragraph](../../../assets/shared/ui/paragraph_page.png)

   **Paragraph**—provides access to the [Paragraph](../../12-text/08-paragraph-formatting.md) panel for advanced paragraph settings.
- ![Left Align](../../../assets/shared/ui/Left_Align.png)

   **Left Align**—sets the paragraph alignment to the left margin.
- ![Centre Align](../../../assets/shared/ui/Centre_Align.png)

   **Centre Align**—sets the paragraph alignment to be equidistant from the left and right margins.
- ![Right Align](../../../assets/shared/ui/Right_Align.png)

   **Right Align**—sets the paragraph alignment to the right margin.
- ![Justified](../../../assets/shared/ui/Justified_All.png)

   **Justified** (with additional pop-up menu options).
- ![Justified Left](../../../assets/shared/ui/Justified_Left.png)

   **Justified Left**—sets the paragraph alignment to both the left and right margins. The last line of a paragraph is left aligned.
- ![Justified Centre](../../../assets/shared/ui/Justified_Centre.png)

   **Justified Centre**—as with Justified Left, however, the last line of a paragraph is centre aligned.
- ![Justified Right](../../../assets/shared/ui/Justified_Right.png)

   **Justified Right**—as with Justified Left, however, the last line of a paragraph is right aligned.
- ![Justified All](../../../assets/shared/ui/Justified_All.png)

   **Justified All**—as with Justified Left, however, the last line of a paragraph is justified regardless of length (sometimes known as Force-Justified).
- ![Top Align](../../../assets/shared/ui/topaligned.png)

   **Top Align**—sets the cell text alignment to adhere to the top margin.
- ![Centre Align](../../../assets/shared/ui/verticalcentrealigned.png)

   **Centre Vertically**—sets the cell text alignment to be equidistant from the top and bottom margins.
- ![Bottom Align](../../../assets/shared/ui/bottomaligned.png)

   **Bottom Align**—sets the cell text alignment to adhere to the bottom margin.
- ![Justify Vertically](../../../assets/shared/ui/Justified_All.png)

   **Justify Vertically**—sets the cell text alignment to both the top and bottom margins.
- ![Bulleted List](../../../assets/shared/ui/listbullet.png)

   **Bulleted List**—inserts a bulleted list.
- ![Numbered List](../../../assets/shared/ui/listnumber.png)

   **Numbered List**—inserts a numbered list.
- **Paragraph Leading**—controls the distance between text baselines (vertical gap between lines) within the paragraph. Type directly in the text box or select from the pop-up menu.
- ![Typography](../../../assets/shared/ui/typography_page.png)

   **Typography**—provides access to the **Typography** dialog for advanced typography settings.

> **Tip:** When setting the Leading, specifying a unit of measurement (i.e., mm or inches) will set an **Exact** distance, while specifying a percentage will set a **% Height** based on the text's font size.
