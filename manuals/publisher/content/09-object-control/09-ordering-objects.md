# Ordering objects

Every object on the page occupies a specific position within a design's z-order (stacking order). With overlapping objects, this will determine which parts of the object are exposed and which are hidden.

When objects are placed or drawn, they are assigned a position in the currently selected layer's z-order. This initial position is determined by object targeting. However, all objects can be repositioned within a layer's z-order as needed.

![Alignment example](../../assets/shared/order.jpg)
*Before and after z-order repositioning.*

**To change an object's z-order position:**

1. Select one or more objects.
2. From the Toolbar, choose one of the following:
  - **Move to Back**—repositions the selected object(s) at the bottom of the layer.
  - **Back One**—moves the selected object(s) down one position in the layer.
  - **Forward One**—moves the selected object(s) up one position in the layer.
  - **Move to Front**—repositions the selected object(s) at the top of the layer. Keyboard shortcut: `Shift` + `Cmd` + `]`

  > **Note:** The above options are also available from the **Layer** menu's **Arrange** submenu.

> **Tip:** You can also reposition or nest objects using the **Layers** panel.
