# Vector Crop Tool

The **Vector Crop Tool** allows you to remove portions of a selected object (or grouped objects) non-destructively and to specific aspect ratios. Images can also be cropped.

**To apply a crop:**

With the **Vector Crop Tool** selected, do any of the following:

- Drag a corner handle to apply an unconstrained crop from the selected corner. Cropping an image from a corner will maintain the image's aspect ratio.
- Drag from an edge handle to apply a vertical or horizontal crop from the chosen edge.

**To reposition objects within a crop area:**

- With the **Vector Crop Tool** selected, drag within the crop area.

> **Note — Modifier keys:** When using the Vector Crop Tool, the following modifier keys can be used while applying a crop:
>
> - The `Shift`  constrains the object's aspect ratio during cropping. You can use this modifier when cropping an image from an edge handle.
> - The `Alt`  temporarily disables global snapping.
> - The `Cmd`  applies the crop from the center.
> - **macOS:** The `Ctrl`  allows the crop area to be rotated about its opposite handle.
> - **Windows:** Upon starting the rotation process, pressing the right mouse button lets you rotate the crop area around its opposite handle.
>
> These modifiers can be used in combination.
