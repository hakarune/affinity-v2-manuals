# Creating master pages

By placing a design element on a master page and then applying that master to other pages, you ensure that all the pages incorporate that element. Of course, each individual page can have its own independent 'foreground' elements.

> **Note:** Master pages can be populated by copying and pasting content from a publication page to them, and by creating objects directly on them.

**To add a master page:**

1. On the **Pages** panel, select **Add Master** on the **Master Pages** window.
2. On the dialog that appears:
  1. (Optional) Type a **Name** for the master page.
  2. If the document has facing pages, choose whether the master page will have an **Ambidextrous** or a **Facing** page layout.
  3. Set the **Page Count** for the master.
  4. If the spread has two or more pages, set the **Spine Location** among them, e.g. you can locate it after the first page in a four-page spread to have the spread only fold outwards to the right.
  5. Set the master page's **Dimensions** and **Margins** as required.
  6. Select **OK**.

> **Note:** The default name assigned to a new master page can be changed to be more meaningful, e.g. 'Master B' could be renamed 'Intro master'.
>
> To quickly rename a master page, select it on the Pages panel and then click its name and type.

**To edit a master page's properties:**

1. On the **Pages** panel,  the master page, then select **Spread Properties**.
2. On the dialog that appears:
  1. (Optional) To select multiple masters whose properties you wish to edit, click their thumbnails.
  2. Edit the master's name (if only one master is selected), dimensions and scaling settings as needed.
  3. Select **OK**.

**To copy master pages (using drag and drop):**

On the **Pages** panel:

1. Drag a master page.
2. Hover to the left or right of a master page's thumbnail, where you want to create a copy.
3. Hold the `Cmd`  and then drop the master page.

Alternatively, -click a master page's thumbnail and select **Duplicate** to create a copy of the master page immediately after the original.

> **Note:** When copying master pages, be careful not to drop one master onto another, which will apply the former to the latter.

> **Note:** Master pages' thumbnails can be rearranged into a preferred sequence using drag and drop.
