# Hyperlinks

Hyperlinks allow you to jump to specific pages, files or web addresses (URLs) with a single click.

## About hyperlinks

Hyperlinks make it easy to navigate between areas in your publication or to access external resources—web pages, or files stored on the reader's local storage. Email addresses can be also linked to, which will launch the reader's email app and set up a message to a specified email address.

Hyperlinks created in Publisher are included when your document is exported as a PDF. Additionally, if you create a TOC or index and request hyperlinks on export, the TOC or index will be furnished with hyperlinks as appropriate.

> **Note:** It is important to note that not all varieties of PDF support interactive features. Additionally, not all PDF viewers support the full range of interactive features; for example, hyperlinks to files do not work in Apple's Preview app.

**To insert a hyperlink:**

1. Make an insertion point within the word or select the full range of text you wish to be hyperlinked. Then do one of the following:
  - From the **Text** menu, click **Interactive** and then select **Insert Hyperlink**.
  - From the **Hyperlinks** panel (enabled via **Window>References**), select **Add Hyperlink**.
2. In the **Hyperlink Properties** dialog, do the following:
  1. Choose a hyperlink **Type**.
  2. Depending on the link type, specify the destination: select a page number, section, existing anchor or external file, or type or paste the web page or email address to be linked.
  3. (Optional) When inserting a hyperlink in a data merge layout and the target is a URL, an anchor, an email address or a file referenced in a field of a data merge source, check **From Data Merge** and then select the **Field** that contains target information.
  4. (Optional) For a file link, tick **Include File on Export** to have Publisher create a copy of the file alongside the PDF (when exporting to a PDF version that supports hyperlinks).
  5. (Optional) If the link is applied to text, choose a **Character Style** for the text.
  6. Click **OK**.

> **Note:** The options on the Hyperlink Properties dialog change according to the Hyperlink Type chosen.

> **Note:** Including an https:// or mailto:// prefix when you type a web page or email address hyperlink is optional.

> **Warning:** When a link's **Include File on Export** option is ticked and you export to PDF, Publisher makes a copy of the relevant file alongside the PDF. The link is amended to be relative, so moving the PDF and the external file together to a new location maintains the link between them. If the aforementioned option is not ticked, the file's full original location is hardcoded into the PDF and expected to exist on the reader's device.

**To edit a hyperlink:**

1. On the **Hyperlinks** panel, double-click the hyperlink you wish to edit.
2. Update the hyperlink's settings in the **Hyperlink Properties** dialog.

**To rename a hyperlink:**

1. On the **Hyperlinks** panel, select the hyperlink you wish to rename.
2. After a brief pause, click the hyperlink's name to begin editing it, make your changes, then press `Return` .

**To go to a hyperlink's source in the document:**

1. On the **Hyperlinks** panel, select a hyperlink.
2. Click **Go to Source**.

**To go to a hyperlink's target:**

1. On the **Hyperlinks** panel, select a hyperlink.
2. Click **Go to Target**.

**To remove a hyperlink:**

1. On the **Hyperlinks** panel, select the unwanted hyperlink.
2. Click **Remove Hyperlink**.
