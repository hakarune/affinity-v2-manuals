# Exporting add-ons

Custom content (with the exception of fonts) can be exported as an add-on file to share with other people or import into your other apps.

> **Note:** Exporting and importing add-ons allows you to use your custom content across multiple personal devices. To use custom content in Affinity apps on the same device, it is usually more convenient to [link it](02-linking-custom-content-across-apps.md).

## To export add-ons

For any type of add-on listed in the table below, follow the corresponding steps, then browse to where you want to export your add-on as a file and click **Save**.

| Add-on type | File extensions | To export |
| --- | --- | --- |
| Assets | .afassets | On the **Assets** panel:  Select the category to export. Select **Export Assets** from the Panel Preferences menu. |
| Document templates | .aftemplate | Open the required document, then select **File**>**Export as Template**. |
| Styles | .afstyles | On the **Styles** panel:  Select the category to export. Select **Export Styles** from the Panel Preferences menu. |
| Swatches palettes | .afpalette | On the **Swatches** panel:  Select the palette to export. Select **Export Palette** from the Panel Preferences menu. |
