# Supported file formats

Affinity Publisher is capable of opening, importing, placing and exporting a range of document, raster and vector graphic formats directly.

Opening a file will launch the document either natively or will import a file's content. Placing a file onto areas of the page will either link to the original file or embed a copy of its contents into Affinity Publisher. Export will make sharable or ready for publishing.

| Open/Import | Place | Export |
| --- | --- | --- |
| Affinity template (.aftemplate) |  | Affinity template (.aftemplate) |
| Affinity Designer 2 (.afdesign) and Affinity Photo 2 (.afphoto) | Affinity Designer 2 (.afdesign) and Affinity Photo 2 (.afphoto) |  |
| PDF<sup>2,3</sup> | PDF<sup>3</sup> | PDF |
| Adobe InDesign (IDML only)<sup>1,2</sup> | Adobe InDesign (IDML only)<sup>1</sup> |  |
| Adobe Illustrator/Photoshop<sup>2</sup> | Adobe Illustrator/Photoshop | Adobe Photoshop |
|  | Adobe Freehand<sup>6</sup> |  |
| Common raster graphics (including HEIF, JPEG, JPEG-XL, PNG<sup>7</sup>, RAW, TIFF, WEBP) | Common raster graphics (including HEIF, JPEG, JPEG-XL, PNG<sup>7</sup>, RAW, TIFF, WEBP) | Common raster graphics (GIF, JPEG, PNG<sup>7</sup>, TIFF, JPEG-XL) |
| Common vector graphics (EPS, SVG) | Common vector graphics (EPS, SVG) | Common vector graphics (EPS, SVG) |
| CAD DWG/DXF<sup>5</sup> | CAD DWG/DXF<sup>5</sup> | CAD DWG/DXF<sup>5</sup> |

|  | J2K, JP2 |  |
|  | OpenEXR |  |
|  | Radiance EXR |  |

<sup>1</sup> When exporting from InDesign, choose **File>Save As** and select the **InDesign CS4 or later (IDML)** option. INDD import is not supported.

<sup>2</sup> Imported file has to be saved as a Publisher file.

<sup>3</sup> JBIG2 PDF encoding is supported.

<sup>4</sup> Includes JPEG-XR 101010 (e.g. XBOX screen captures).

<sup>5</sup> DWG (R12-R14, 2000-2018) and DXF (R9-R14, 2000-2018).

<sup>6</sup> Multi-page Freehand files open with each page concatenated onto a single page. Add file extension .fh10 or .fh11 to import. Text import is not supported.

<sup>7</sup> Includes 32-bit HDR support ([PNG specification - Third edition](https://www.w3.org/TR/png-3/)) for interchanging HDR broadcast imagery in a lossless format. Legacy PNG files exported from Photoshop with cICP data embedded in an ICC profile can be imported.
