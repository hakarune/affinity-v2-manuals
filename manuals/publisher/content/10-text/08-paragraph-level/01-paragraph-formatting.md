# Paragraph formatting

Paragraph formatting describes text attributes which are applied at a paragraph level.

Paragraph formatting includes attributes such as:

- **Alignment**—controls which side of the text frame paragraph text is aligned with.
- **[Spacing](02-leading-and-inter-paragraph-spacing.md)**—controls the spacing between lines and between paragraphs.
- **[Leading](02-leading-and-inter-paragraph-spacing.md)**—determines the distance from one text baseline (the line on which a line of text appears to sit) to the next.
- **Justification**—determines where space is added between words in a paragraph to align the edges of each line with both sides of the margin.
- **[Flow options](../07-text-frames/04-flowing-text-through-frames.md)**—Flow options—controls where on the page your paragraph starts and inter-paragraph relationships. See [Paragraph panel](../../21-panels/18-paragraph-panel.md) for further information.
- **[Bullets and numbering](04-bullets-and-numbering.md)**—allows you to turn a series of paragraphs into bulleted, numbered or multi-level lists.
- **[Tab stops](06-tabs.md)**—controls how text is positioned at specific horizontal locations in a text frame.
- **[Drop caps](08-drop-caps.md)**—increases font size of initial characters in a paragraph, extending over multiple lines.
- **[Indents](03-indents.md)**—these can only be applied to full paragraphs or stories.
- **[Decorations](01-paragraph-formatting/01-decorations.md)**—these can be used to differentiate blocks of text using decorative styles that will always move relative to the text.
- **Widow and orphan control**—this can be used to fix instances in which lone words and lines appear separately from the rest of a paragraph at the top or bottom of a text column.

This type of formatting can be applied to artistic text, but is more appropriate for frame text.

With your text (or text object) selected, paragraph formatting settings are available from the context toolbar, the **Text** menu, and the **Paragraph** panel.

The positions of paragraph formatting attributes are displayed on the text ruler, which can be activated via the **View** menu.

A frame text ruler can be displayed directly above any active text frame to visually set paragraph indents and tab stops.

**To access the Paragraph panel:**

Do one of the following:

- ![Paragraph](../../../assets/shared/ui/paragraph_page.png) With text selected, on the context toolbar, click **Paragraph**.
- From the **Window** menu, select **Text>Paragraph**.

**To activate the text ruler:**

Do one of the following:

- From the context toolbar, ensure that **Frame Text Ruler** is switched on. The text ruler will appear when an insertion point is made in the text.
- From the **View** menu, ensure that **Show Text Ruler** is checked. The text ruler will appear when an insertion point is made in the text.

Once activated the text ruler will display on any text frame you subsequently select.

> **Tip:** The text ruler can be moved vertically nearer to tab or indent formatting using the up and down arrow header. To reset the ruler's position, double-click on it.
