# Features of Affinity Publisher

Here's an overview of Affinity Publisher's features. Choose a category from the menu below, which includes options to view all features, or only those that are new in this version—marked with a red bullet (▪).

## New in V2.6

- [Multiple-page spreads](../05-pages-spreads-and-sections/11-multiple-page-spreads.md)
  - Create foldable spreads, e.g. gatefolds, trifolds and accordion-fold
  - Manage spreads' spine position by creating them as [master pages](../05-pages-spreads-and-sections/12-master-pages/02-creating-master-pages.md)
  - Easily extend spreads using a [dialog](../05-pages-spreads-and-sections/11-multiple-page-spreads.md) or [drag and drop](../05-pages-spreads-and-sections/03-arrange-pages.md)
- [PDF accessibility](../14-publishing-and-sharing/06-pdf-publishing/03-accessible-pdfs.md) improvements
  - Optimize content for screen readers
  - [Dedicated Reading Order panel](../21-panels/22-reading-order-panel.md)
  - Help assistive technologies understand document structure by assigning tags to your paragraph styles
- [Preflight](../14-publishing-and-sharing/05-preflight.md) warning if text flows contain mismatched scaling
- [Generate QR codes from data merge source fields](../13-references/11-data-merge.md)
- [Move](../05-pages-spreads-and-sections/03-arrange-pages.md) or [copy](../05-pages-spreads-and-sections/04-copy-and-duplicate-pages.md) pages using a dialog
- Apply Alt and Extended Description XMP [tags](../21-panels/31-tags-panel.md) to images
- [Color panel](../21-panels/05-color-panel.md)’s Color Picker now applies to selected object
- [Toggle marquee select intersection](../09-object-control/01-selecting-objects.md) behavior with `Cmd` key

## Power, performance and compatibility

- Optimized for:
  - **macOS:** Grand Central Dispatch (GCD)
  - **macOS:** OpenGL
  - **macOS:** Core Graphics
  - **Windows:** Direct3D
  - 64-bit engine
  - **macOS:** GPU hardware acceleration (Metal) for integrated, discrete and external GPUs
  - **Windows:** Hardware GPU acceleration (OpenCL) for integrated, discrete and external GPUs
- Display support
  - **macOS:** Regular, Retina and expanded gamut DCI-P3
  - **Windows:** Wide color gamut (Display P3)
  - HiDPI
  - **macOS:** EDR
  - **Windows:** HDR (Windows; >400 nits recommended)
- **macOS:** Mac with Apple M1/M2/M3 chip or Intel processor
- **macOS:** macOS Catalina 10.15 or later
- **macOS:** Up-to-date tablet support
- **macOS:** Multi-touch support
- **Windows:** Surface Studio with Surface Pen and Surface Dial support
- **macOS:** Force Touch support (Magic Trackpad 2/MacBook/MacBook Pro)
- **macOS:** Touch Bar support (MacBook Pro)
- **Windows:** DirectX 10 compatible
- **Windows:** Windows® 11, Windows® 10 May 2020 Update (2004, 20H1, build 19041) or later
