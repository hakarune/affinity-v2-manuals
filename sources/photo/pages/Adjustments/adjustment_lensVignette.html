Remove Lens Vignette/Post Crop Vignette

The Remove Lens Vignette adjustment corrects unwanted vignetting by modifying the brightness at the edges of an image. The Post Crop Vignette adjustment achieves the same effect on cropped images.

This adjustment is only available in Develop Persona.

Settings

The following settings can be adjusted:

  • Intensity—sets the type and value of the correction. Drag the slider to set the value.
  • Scale—controls the size of the correction. Drag the slider to set the value.
  • Hardness—controls how much feather/blur is applied to the transition. Drag the slider to set the value.
