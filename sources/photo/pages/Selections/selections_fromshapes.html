Pixel selections from shapes

You can convert a curve or shape (path) drawn using the Pen Tool into a selection. When created from a curve, the resulting selection will be closed using a straight line between the end nodes.

The original line or shape will be discarded when the selection is created. Ensure you keep a copy of your original line or shape if you wish to use it later in your project.

To create a pixel selection from a drawn line or shape (path):
  1. Do one of the following:
    • Using the Pen Tool draw a curve or closed shape on your page.
    • Select a previously drawn curve or shape and then select the Pen Tool.
  2. From the context toolbar, click Selection.

You can convert geometric shapes created using the shape tools into selections by converting them to curves and then using the procedure above or creating a selection from the shape's layer.
