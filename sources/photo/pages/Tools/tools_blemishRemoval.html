Blemish Removal Tool

The Blemish Removal Tool enables you to remove small imperfections from images with a single click.

The tool is available in both Photo Persona and Develop Persona.

Settings

The following settings can be adjusted from the context toolbar:

  • Width—the area size in pixels. Type directly in the text box or drag the pop-up slider to set the value.
