Document units

Document units allow you to set a physical measurement unit for your document that suits your way of working, whether imperial, metric or in pixels.

As you create a new document, its document units will be set depending on the preset chosen. For example, presets for A-series page sizes will use millimeters as default, while US page sizes and photo page sizes use inches; for web-related page sizes, pixels are used.

You'll encounter document units when you're:

  • Moving/resizing layer content using the Transform panel
  • Drawing new vector content
  • Measuring between layer content and page elements
  • Using guides and grids
  • Using rulers

At any time, you can change your document units. These are saved with the document.

To set your document units for new documents:
  1. On the File menu, select New.
  2. From the New Document dialog, choose a preset, which sets the document units for that preset type.
  3. (Optional) From the Document Units pop-up menu, change the unit type if needed, e.g. millimeters to pixels.
To change your document units at any time:

Do one of the following:

  • With the Zoom Tool selected, choose a unit of measurement from the Units pop-up menu on the context toolbar.
  • If you have rulers switched on, -click the ruler intersection and choose a unit type from the pop-up menu.
