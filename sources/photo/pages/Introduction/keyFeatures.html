Features of Affinity Photo 2

Here's an overview of the features of Affinity Photo 2. Choose a category from the menu below, which includes options to view all features, or only those that are new in this version—marked with a red bullet (▪).

New in V2.6

  • Machine Learning (ML) selections:
    • Object Selection Tool
      • Intelligent object selections
      • Select multi-part components
      • Optional control over soft edges and matting
      • Works on image and RAW layers
    • Select Subject
      • Automatic selection of the main subject on raster or image layers
      • Record as a macro for faster workflows
      • Works on image and Raw layers
  • Search within current Brushes Panel category
  • Load image layer in Develop, Liquify and Tone Mapping Personas as raster layer*
  • Image/Raw layer improvements:
    • Merge Down/Selected will rasterize and merge
    • Inpainting will rasterize and apply*
    • Paint Brush and Erase tools, on painting, will nest the new layer or mask, respectively
    • Deleting pixel selections will rasterize or mask content*
    • Duplicating pixel selections will create masked or rasterized pixel content from just that copied area*
    • Moving marquee pixel selections with -drag will rasterize the layer and move just that content
  • Live Perspective filter shortcut of +T
  • Flood Select, Marquee and Freehand selection tool improvements:
    • Tools now use to add; to subtract
    • Antialiasing enabled by default
  • Rectangular Marquee Tool can be drawn from center
  • Marquee tools use the modifier to constrain*
  • Color panel’s Color Picker automatically colors selected object(s)
  • Toggle marquee select intersection behavior with key
  • Right-click Layers Panel options for Clear Mask and Fill Mask
  • Inpainting and Patch tools remember previously chosen target layer
  • Updated SerifLabs RAW engine, including support for:
    • Canon EOS R5 Mark II
    • Fujifilm GFX 100S II
    • Google Pixel 9 Pro/Pro XL/Pro Fold
    • Leica D-LUX8
    • Leica Q3 43
    • Nikon Z 6 III
    • Panasonic DC-GH7
    • Sony ZV-E10 II

*Optional behaviors via Assistant/Settings

Raw development
