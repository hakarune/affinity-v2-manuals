Gradient Map adjustment

The Gradient Map adjustment maps the equivalent grayscale range of an image to a specified color gradient. This provides an effective (and creative) way of recoloring an image.

Apply this adjustment via the Adjustment button on the Layers panel or via Layer > New Adjustment.

Settings

For dialog settings, see the Gradient editing topic.

To create a black and white image, ensure the gradient contains only grayscale values.
