Setting a cross-reference's target

Each cross-reference is linked to a single target. The target can be on the same page, or a different page in the current document or another book chapter.

When inserting or editing a cross-reference, the following options are available for selecting a target:

  • Link to—Select the type of targets—Anchor, Paragraph, or Index Mark—to show in the targets list.
  • Target chapter—Select the book chapter that contains the target for the cross-reference. (Available when the current document is a chapter of a book that is open on the Books panel. Only chapters whose documents are open can be selected.)
  • Filter style—When linking to a paragraph, select a paragraph style that must be applied to a target for it to be shown in the targets list.
  • Filter text—When linking to a paragraph, enter text that a target must contain for it to be shown in the targets list. Click the magnifying glass icon to select whether the filter text must appear at the target's start or anywhere in the first 100 characters.
  • Targets list—Shows all targets of the selected type and matching the filter criteria. Select an entry to link the cross-reference to it.

When you link a cross-reference to a paragraph or an index mark, it will ultimately link to an anchor at the paragraph's start/the index mark's position. Affinity uses any anchor that already exists at the position, or create a new one there.

Anchors can be used to target non-textual content, such as your publication's figures in the form of picture frames, shapes and placed documents.

Cross-references cannot be linked to targets within placed documents.

To link a cross-reference to a target:

When inserting or editing the cross-reference:

  1. On the Link to pop-up menu, select the type of targets to display in the targets list: Anchor, Paragraph or Index Mark.
  2. (Optional) Select the Target chapter that contains the required target.
  3. (Optional) When linking to a paragraph, use the filter options to limit what appears in the targets list.
  4. From the targets list, select the required target.

The targets list can be sorted by clicking a column heading. Each click toggles between ascending and descending order.

To filter the paragraphs shown in the targets list:
  • Based on text formatting, select a paragraph style or [Any Style] from the Filter style pop-up menu.
  • Based on text content, type in the text box and select from Filter Options whether the text must appear at the start or anywhere within a paragraph's first 100 characters.

The filter style and text options can be used individually or in conjunction.
