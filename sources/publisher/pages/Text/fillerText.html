Filler text

For frame text, if you're designing before full copy has been written, you can use filler text as placeholder copy to help you progress with your project.

By default, filler text is just a single Lorem Ipsum text field, that autofills on frame resize. Filler text doesn't behave as plain text (i.e., it is not editable, with selection being limited to the entire block) but you can change this to normal editable text per frame or use plain text by default.

If you prefer your own custom text, this can replace the Lorem Ipsum text. For spell-checking purposes, you can set the language to go with this text.

When filler text is inserted, its starting sentence is chosen randomly. Custom filler text should be multiple sentences and/or paragraphs long to increase the likelihood that different text frames/linked text frame sequences begin with different words, avoiding a repetitive appearance.

To add filler text:
  • With the text frame selected, from the Text menu, select Insert Filler Text.

A check mark next to the Insert Filler Text menu entry indicates that a selected text frame uses filler text.

Settings (or Preferences)

Related behaviors can be adjusted from the app's settings:

  • General>Insert filler text as text
To convert filler text to normal editable text (per text frame):
  • -click any portion of filler text and choose Expand Field.
To use plain text as filler text by default:
  1. From the Affinity Publisher menu, select Settings (or Preferences).
  2. From the Edit menu, select Settings.
  3. On the General tab, check Insert filler text as text.
To use custom text as filler text:
  • From the Affinity Publisher menu, select Settings (or Preferences).
  • From the Edit menu, select Settings.
  • On the Filler Text tab, set a spelling language from the pop-up menu and then type or paste your custom text into the main text frame.
  • Click Close.

Custom text is 'live' in that a text frame's filler text will update automatically if it is modified in Settings (or Preferences).

To manage filler text, choose one of:

  • Save as Default—Click to make text in the text frame the default; all subsequent filler text added to text frame will use this text.
  • Revert to Default—Reverts unsaved modified filler text back to the previously saved filler text.
  • Factory Reset—Reverts filler text back to Lorem Ipsum text.
