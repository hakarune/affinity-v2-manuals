Document statistics

Affinity Publisher can optionally display a count of the number of words, characters, paragraphs or lines in the current document or selection.

Document statistics can be helpful when commissioning writers to ensure they provide a suitable amount of text, e.g. for magazine and newspaper articles.

About statistics

When shown, the count is located in the status bar, between the preflight status indicator and the hintline.

The count persistently displays one of five units of measurement: words, characters, characters including spaces, lines or paragraphs.

The value changes according to your current selection:

  • When no text objects are selected, the count is for all text objects in the current document.
  • When one or more text objects are selected, the count is for text in all of them.
  • When a linked text frame is selected, the count includes text in all frames linked to it.
  • When the text insertion point is within frame, artistic or table text, all text in the text object is counted.
  • When a range of text is selected, only that range is counted.

The count updates soon after you stop typing.

Overset text

The count may display a second value in brackets. This value is the amount of overset text in the selection (including unselected frames linked to it), or in the whole document (if nothing is selected).

To show/hide the count:
  1. On the View menu, select Show Word Count.
To choose the count's unit of measurement:
  1. On the status bar, click the count.
  2. Choose a unit of measurement from the pop-up menu.

At any time, click the count to see the value in all available units. Press the or click away from the pop-up menu to close the menu without selecting a different unit.
