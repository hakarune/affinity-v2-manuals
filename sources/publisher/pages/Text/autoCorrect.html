Auto-Correct and Check Spelling While Typing

Affinity Publisher includes powerful error-correction and automatic formatting tools which are applicable to frame text, table text, and artistic text.

  • The Auto-Correct feature aids formatting, and overcomes typographic and common typing errors.
  • Check Spelling While Typing will underline spelling mistakes as you type. This marks possible problem words in your story text.

If you prefer to address spelling issues in larger doses at the same time, you can run the Spell Checker anytime.

Auto-Correct

Auto-Correct intelligently and automatically replaces or formats your text while typing. Several types of correction are possible:

  • Auto-Correct settings: formats your text into numbered or bulleted lists, and controls capitalization, superscript use, quotes, and tabs.
  • Replacements: provides a preset correction list or common 'typos', with the option of adding your own custom letter combinations and substitutions to be applied automatically as you type. Word phrases or combinations are also included in auto-correction.
  • Abbreviations: prevents inadvertent capitalization following abbreviation use in your publication. The abbreviation list declares these abbreviations, again with the option of adding your own abbreviations.

Smart quotes

If the Auto-Correct option Change straight quotes to typographic quotes is selected, anytime you type straight quotation marks (i.e., the " or ' characters), Affinity Publisher will automatically update this to the appropriate 'curly' version of the quotation mark for the text's language. You can use Edit>Undo immediately after auto-correction to revert to straight quotes.

Alternatively, to override auto-correction, press ' for a straight single quote or ' for a straight double quotation mark.

Check Spelling While Typing

This feature, enabled by default, indicates possible problem words in your text using red underline, and offers (via -click) a range of alternative correct spellings to replace the problem words.

Ensure the Check Spelling While Typing feature is turned on (from Text>Spelling).

To set Auto-Correct settings:
  1. From the Affinity Publisher menu, select Settings (or Preferences).
  2. From the Edit menu, select Settings.
  3. On the Auto-Correct tab, check your desired auto-correct options.

For any checked options, auto-correction will be enabled.

To add custom misspellings to the replacements list:
  1. From the Settings (or Preferences) Auto-Correct tab, set the Language pop-up menu to set language-specific replacements.
  2. Enter your custom replacement using the Replace and With boxes—this is the word to be replaced automatically as you type and the text to be automatically inserted in place of the word in the Replace field.
  3. Click Add to add the new entry to the list.
To modify a replacement entry:
  1. From the Settings (or Preferences) Auto-Correct tab, select an existing replacement entry and enter a different replacement word in the With box.
  2. Click Replace.
To add to the Abbreviations list:
  1. From the Affinity Publisher menu, select Settings (or Preferences).
  2. From the Edit menu, select Settings.
  3. On the Abbreviations tab, add your own abbreviation to the input box and click Add.
To replace/ignore Check Spelling While Typing marked words:

Do one of the following:

  • To replace a marked word, place an insertion point in a marked word then -click to choose an alternative spelling from the context menu.
  • To ignore (leave unmarked) this instance of the marked word, choose Ignore Spelling.
To disable Check Spelling While Typing:
  • From the Text menu, select Spelling, and then uncheck Check Spelling While Typing.
