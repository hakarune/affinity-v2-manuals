Tagging layers

Layers can be tagged with a colour to help differentiate specific layer content in the Layers panel.

Tagging provides a useful additional means of organising layer content beyond grouping layers, as it allows you to organise a set of layers without affecting the layer order. All layers that share the same tag colour can be selected at once from the Layers panel or Select menu.

To assign a tag colour to a layer(s):
  1. (Optional) On the Layers panel, select multiple layers.
  2. Do one of the following:
    • -click Toggle Visibility, and select a colour tag from the pop-up menu. For multiple selected layers, any of the selected layers can be targeted.
    • -click a layer and select a colour swatch from the pop-up menu.

When you assign a tag colour to a layer group, it is also applied to layers within the group except any that have a colour tag already.

To remove a tag colour:
  • With a layer (or multiple layers) selected, on the Layers panel, -click and choose the first colour swatch (white with a red line through it). Tag colours are removed from the entire selection.

When you remove a tag colour from a layer group, it is also removed from any layers of the same colour within the group.
