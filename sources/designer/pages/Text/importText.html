Importing text

Importing text from a file lets you introduce already existing text into your document.

Typically text is placed into a chosen text frame but you can also import text as artistic text or path text.

You can import text files in Rich Text Format (.rtf) and plain text (.txt) formats. If your text editor saves as or can export to one of these formats, you can use its output in Affinity.

To import text into an empty text frame:
  • With the Frame Text Tool active, do one of the following:
    • On the File menu, select Place. In the pop-up dialog, navigate to and select a file, and click Open. If the text frame was not selected or did not contain an insertion point, click the frame.
    • Drag and drop the file from a folder on your operating system onto the text frame.
    • Paste (V) previously copied text from Microsoft Word, Adobe InDesign or another text source.
    • Paste (+V) previously copied text from Microsoft Word, Adobe InDesign or another text source.
    • -click the text frame, and select Paste.

Selecting multiple text files to import will load the text files into the Place Images panel. To place the currently selected item from the panel into a text frame by clicking the frame or dragging to create a new one.

To import a text file's contents into a populated text frame at a specific location:
  • Select the Frame Text Tool.
  • Click at a chosen text position to make an insertion point.
  • On the File menu, select Place as described previously.
To replace all frame text in a text frame with a text file's contents:
  • Select the Move Tool.
  • Select the text frame, ensuring that you don't double-click it (making an insertion point).
  • On the File menu, select Place as described previously.
To import text as artistic text or path text:
  • Create an insertion point in artistic or path text.
  • On the File menu, select Place as described previously.
