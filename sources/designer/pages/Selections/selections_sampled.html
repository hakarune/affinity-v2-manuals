Sampled colour pixel selections

In the Pixel Persona, you can create a pixel selection by sampling colours from a pixel layer.

Settings

The following settings can be adjusted from the dialog:

  • Tolerance—determines how closely pixels must match the selected colour to be included in the selection. For lower tolerance settings, pixels must be very close in value to the clicked pixel. For higher tolerance settings, pixel colour can vary widely from the clicked pixel. Drag the slider to set the value.
  • Model—determines the colour model used when sampling. Select from the pop-up menu.
To create a pixel selection from a sampled colour:
  1. Select a pixel layer.
  2. From the Select menu, choose Select Sampled Colour.
  3. Click on your pixel layer to select the sampled colour.
  4. Adjust the settings in the dialog.
  5. Click Apply.
